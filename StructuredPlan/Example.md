## Example Translation Workflow


step 1: Screenshot the paragraph to be extracted using 'Snipping Tool' 

![[Pasted image 20261108150917.png]]

step 2: extract text using OCR tool inside the Snipping Tool --> Select all --> copy text --> paste in a note block of obsidian markdown file specified by the Human translator for this task:



§ #1

>[!summary] Arabic Text
>• فهل من العقل افتراض أن قوانين الاحتراق الداخلي تكفي لخَلْق: الموتور، وشرارة
الاحتراق، والبنزين، والسائق، والطريق؟
• ما أصبح يُفكر الملاحدة بهذه الطريقة إلا لأنهم يواجهون إشكالاتٍ حقيقية مزعجة
لن يخرجوا منها إلا بهذه الفَرضیات الغریبة.


Step 3: paste the arabic text inside DeepL app and translate to English and Kurdish Sorani langauges then place them back inside the Markdown file as shown below: 

>[!summary] English Text
>• Is it reasonable to assume that the laws of internal combustion are sufficient to create: the engine, the spark,
the fuel, the driver, and the road?
• Atheists have come to think this way only because they face real, troubling problems
from which they can escape only through these strange assumptions.


>[!summary] Kurdish Text
>• ئایا گونجاوە وا دابنرێت کە یاساکانی سووتانی ناوەکی بەس بن بۆ دروستکردنی: بزوێنەر، بریسکە، بەنزین، شۆفێر و ڕێگا؟
• بێباوەڕەکان تەنها لەبەر ئەوەی ڕووبەڕووی کێشەی ڕاستەقینە و بێزارکەر دەبنەوە، بەم شێوەیە بیر دەکەنەوە، کە تەنها دەتوانن لە ڕێگەی گریمانەی لەم شێوەیە سەیرەوە خۆیان لێ دەرباز بکەن.


Translation restrictions: 
1) Quranic Ayahs (Verses) Must not be translated and must be placed as (in Arabic languge) is across all translated languages. 
2) images and screenshots of evidences must be placed in the page as is, and they will be dealt with later by the Human translator.


Page numbers must be placed inside a block as shown below:
